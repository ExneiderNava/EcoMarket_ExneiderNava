# 🌿 EcoMarket

**EcoMarket** es una plataforma de comercio electrónico maquetada exclusivamente con **HTML5 Semántico y CSS3 Puro**. El proyecto está diseñado bajo un enfoque *Mobile-First* y una arquitectura limpia de hojas de estilo, ofreciendo una experiencia de usuario fluida, responsiva y fiel a los principios del diseño sostenible sin utilizar una sola línea de JavaScript.

---

## 📋 Descripción del Proyecto
El consumidor moderno busca alineación con sus valores éticos. EcoMarket aborda esta necesidad mediante una interfaz "Clean" que domina el uso del espacio en blanco, tipografías legibles y paletas de colores naturales que transmiten calma y confianza. 

### Desafío Técnico
Al restringir el uso de scripts, este proyecto explota al máximo las capacidades avanzadas de CSS3:
* **Interactividad nativa:** Uso exhaustivo de pseudo-clases (`:hover`, `:active`, `:target`, `:valid`, `:invalid`).
* **Sistemas de diseño:** Combinación estratégica de **CSS Grid** para matrices complejas y **Flexbox** para componentes alineados.
* **Rendimiento:** Optimización de carga gracias a la ausencia de librerías o frameworks externos.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5 Semántico:** Estructuración limpia mediante etiquetas de arquitectura (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`).
* **CSS3 Avanzado:** Selectores avanzados, variables globales, animaciones por keyframes y diseño responsivo adaptado a múltiples rupturas (Desktop, Tablet y Móvil).

---

## 📂 Estructura del Proyecto
El código se organiza de forma modular y obligatoria bajo la siguiente arquitectura de archivos para garantizar su escalabilidad:

```bash
EcoMarket/
├── css/
│   ├── main.css            # Resets globales, variables de color y tipografía base
│   ├── layout.css          # Estructuras principales (Header, Footer, Grid, Flexbox)
│   ├── components.css      # Tarjetas de productos, botones, campos e interactividad
│   └── animations.css      # Reglas @keyframes y transiciones fluidas
├── img/
│   ├── products/           # Imágenes optimizadas del catálogo (.webp)
│   ├── icons/              # Iconografía del sitio
│   └── hero/               # Imágenes de banners principales
├── views/
│   ├── productos.html      # Catálogo y filtros visuales
│   ├── sobre-nosotros.html # Historia de marca y carrusel CSS
│   └── contacto.html       # Formulario inteligente con validaciones nativas
├── index.html              # Página de Inicio (Home)
└── README.md               # Documentación del sistema
```

📦 Instrucciones de Despliegue Local
Sigue estos pasos para visualizar y probar el proyecto en tu entorno local:

Clonar el repositorio:

Bash
git clone 'https://github.com/ExneiderNava/EcoMarket_ExneiderNava.git'
Abrir el proyecto:
Abre la carpeta raíz EcoMarket en tu editor de código preferido (ej. Visual Studio Code).

Ejecutar un servidor local:

Haz clic derecho sobre el archivo index.html y selecciona Open with Live Server.
